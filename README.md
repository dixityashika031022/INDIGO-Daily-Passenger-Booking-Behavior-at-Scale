IndiGo Flight Data Analysis

About the Project

This project analyzes IndiGo flight data to understand flight operations, ticket prices, travel patterns, and overall flight performance.

Objectives

- To analyze flight data.
- To understand ticket price variations.
- To identify travel patterns.
- To visualize flight-related data using charts and graphs.

Dataset

The dataset contains flight-related information used to analyze travel patterns and flight performance.

Tools Used

- Python
- Jupyter Notebook
- Pandas
- Matplotlib

Analysis

The project uses data analysis and visualizations to explore flight data, ticket prices, and travel trends.

Conclusion

This project helps understand flight trends and analyze flight-related information through data visualization.
